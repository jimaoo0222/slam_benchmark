# 真值文件（TUM 格式，8 列）
#
#   timestamp  tx  ty  tz  qx qy qz qw
#
# ── 怎么填 ──────────────────────────────────────────────
#   1. 把下面 3 行示例的【坐标】换成你卷尺量出来的值
#   2. 时间戳先留 0.000 —— 等轨迹跑完之后：
#        python3 ../../scripts/benchmark_eval.py --find-stops traj_lidar.txt
#      它会自动找出「停稳的那几秒」，生成一份带真实时间戳的模板，
#      把那几个时间戳抄回本文件即可
#
# ── 注意事项 ────────────────────────────────────────────
#   · 坐标系：本文件用的是「相对起点」的坐标。
#     如果改用场地绝对坐标，两边必须用同一套（否则误差会是米级）
#   · 时间戳【必须落在轨迹文件的时间范围内】，否则该点会被跳过
#     （跑完看「有效点 N/M」，N 应该等于 M）
#
