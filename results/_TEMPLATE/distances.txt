# 相邻停车点之间的距离（米）
#
# ── 量什么 ─────────────────────────────────────────────
#   只量「点1→点2」「点2→点3」…… 的距离，
#   不需要量每个点的绝对 XY 坐标！
#
#   原因：尺子量绝对坐标要从两个参照面各量一次，
#         参照面本身不一定垂直，误差会累积；
#         而量两点间的直线距离是【相对量】，误差小得多。
#
# ── 怎么量 ─────────────────────────────────────────────
#   机器人走到固定点停稳后，用卷尺量它和上一个停车点的距离。
#   一行一个，按顺序。
#
# ── 重要：各段距离要拉开差距 ───────────────────────────
#   ⚠️ 不要都是 3 m —— 那样算尺度因子时没有区分度，
#      拟合出来的 R² 会很低，工具会警告你。
#      推荐：1 m / 3 m / 5 m 这种有明显差别的组合。
#
# ── 下面 3 行是示例，换成你的实测值 ─────────────────────
1.02
3.01
5.03
