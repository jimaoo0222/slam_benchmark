## 每列怎么来的

| 列 | 从哪来 | 怎么填 |
|---|---|---|
| ① 稳定性 | `protocol_eval.py` 的「最大漂移的中位数」 | 单次运行内，停稳时的漂移 |
| ② 可重复性 | 多个包的轨迹一起跑：`protocol_eval.py bag1_glim.txt bag2_glim.txt bag3_glim.txt` 的「最大离散的中位数」| 同一点在不同包之间的离散 |
| ③ 尺度偏差 | 点间距比值均值 − 1，取百分数 | 例如比值均值 1.0231 → 填 `+2.31` |
| ④ 闭合误差 | `protocol_eval.py` 的「首尾距离」 | 只在闭合回路时有效 |
| 实时倍率 | 算法处理耗时 ÷ 数据时长 | <1 表示比实时快 |
| 失败率 | 3 次里崩溃/发散的次数 ÷ 3 | |

## 注意：采集时的硬要求（否则指标算不出来）

```
- [ ] 每个停车点停稳 5 秒        → 否则 ① 稳定性算不了
- [ ] 各点间距拉开（1 / 3 / 5 m） → 否则 ③ 尺度拟合的 R² 会很低
- [ ] 路径回到原点                → 否则 ④ 闭合误差没有意义
- [ ] 同一路径录 ≥3 个包         → 否则 ② 可重复性算不了
```
